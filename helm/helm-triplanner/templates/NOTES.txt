Triplanner demo services installed.

Namespace: {{ .Release.Namespace }}
Create it before installing:
  kubectl create namespace {{ .Release.Namespace }}

Components:
  - triplanner-kafka: Go HTTP broker (topic/offset/ack, SQLite)
  - triplanner-email: email consumer + BYOK settings
  - triplanner-locations: destinations/activities catalogue (REST, :{{ .Values.locationsService.service.port }})
  - triplanner-trips: trips, members, items and invitations (REST, :{{ .Values.tripsService.service.port }})
  - triplanner-mongo: single-node MongoDB StatefulSet
  - triplanner-trips-postgres: single-node PostgreSQL StatefulSet

RBAC:
  - per-service ServiceAccount
  - ClusterRole + ClusterRoleBinding for TokenReview/SAR
  - kube-rbac-proxy sidecar on HTTP 8443 (local demo only)
  - main app ports remain 8080 (broker) / 4200 (email) / {{ .Values.locationsService.service.port }} (locations) / {{ .Values.tripsService.service.port }} (trips)
  - port-forward 8443; do not expose it outside the cluster

1. Check the rollouts:
   kubectl -n {{ .Release.Namespace }} rollout status deployment/triplanner-kafka
   kubectl -n {{ .Release.Namespace }} rollout status deployment/triplanner-email
   kubectl -n {{ .Release.Namespace }} rollout status deployment/triplanner-locations
   kubectl -n {{ .Release.Namespace }} rollout status deployment/triplanner-trips
   kubectl -n {{ .Release.Namespace }} rollout status statefulset/triplanner-mongo
   kubectl -n {{ .Release.Namespace }} rollout status statefulset/triplanner-trips-postgres

2. Check the probes:
   kubectl -n {{ .Release.Namespace }} port-forward svc/triplanner-email 4200:{{ .Values.emailService.service.port }}
   curl http://localhost:4200/health
   curl http://localhost:4200/ready

3. Check the broker:
   kubectl -n {{ .Release.Namespace }} port-forward svc/triplanner-kafka 8080:{{ .Values.broker.service.port }}
   curl http://localhost:8080/health
   curl http://localhost:8080/ready

4. Check the catalogue:
   kubectl -n {{ .Release.Namespace }} port-forward svc/triplanner-locations {{ .Values.locationsService.service.port }}:{{ .Values.locationsService.service.port }}
   curl http://localhost:{{ .Values.locationsService.service.port }}/health
   curl http://localhost:{{ .Values.locationsService.service.port }}/ready

5. Check trips:
   kubectl -n {{ .Release.Namespace }} port-forward svc/triplanner-trips {{ .Values.tripsService.service.port }}:{{ .Values.tripsService.service.port }}
   curl http://localhost:{{ .Values.tripsService.service.port }}/health
   curl http://localhost:{{ .Values.tripsService.service.port }}/ready

6. BYOK:
   The email service starts with provider={{ .Values.emailService.provider }}.
   Open the app Profile -> Email delivery to add a Resend key.
   No Resend Secret is required for the recruiter demo.

   Places data starts with the committed catalogue. Add a HasData key in
   Settings -> Places data to use live search; results are cached in MongoDB
   for 5 days.
