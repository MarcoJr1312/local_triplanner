# Project skills

Vendored Grafana skills for the SRE/DevOps workflow:

- [`grafana-dashboarding`](./grafana-dashboarding/SKILL.md) — dashboard JSON,
  panels, variables, transformations and links.
- [`grafana-promql`](./grafana-promql/SKILL.md) — query patterns, window sizing
  and error-ratio guards.

Both are vendored from <https://github.com/grafana/skills> (commit `8fb72a5`,
Apache-2.0). The `sre-devops` agent and the Orkai Kubernetes Manifest Delivery
workflow load them for dashboard work.
